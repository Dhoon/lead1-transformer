# 학습 결과 요약 (2026-11-04)

SPEC v0.9 → v1.0 이후 수행한 지도학습 실험 결과를 정리한다. 모든 수치는 **검증 건물 40개**(GroupKFold 5-fold 중 1개 fold) 기준이다.

## 공통 조건

- 하드웨어: Brev Tesla T4 1장
- 학습: 10 epoch × 20,000 샘플, AdamW(lr 3e-4, weight decay 0.01), 학습 Window 1~64일 무작위
- 결측값: `zero_fill`(0 대체), 결측 시간 Loss `include`
- 지표: ROC-AUC / PR-AUC / F1(threshold 0.5). 별도 표기가 없으면 **T=64 고정 Window 평가**
- 양성 비율: 시간 단위 약 2%. 이상 탐지 성능은 ROC보다 **PR-AUC·F1**을 주로 본다
- 「최고 F1」은 검증 정답으로 threshold를 고른 값이라 낙관적이다. 모델 간 비교용으로만 쓴다

## 핵심 결론

**최종 구성(2-2-2 + cosine LR) 5-fold 성능: ROC 0.916 ± 0.023 / PR 0.664 ± 0.058 / F1 0.669 ± 0.056** (9절)

1. **결측 시간 Loss는 `include`로 확정한다.** `exclude_missing`은 결측 시간에 평균 확률 0.72를 줘서 오탐이 쏟아진다(PR 0.19).
2. **결측값 대체는 0 대체(`zero_fill`)가 중앙값 대체보다 낫다.** PR 0.613 vs 0.554.
3. **`pos_weight`는 쓰지 않는다.** 5·10·15·45 모두 확률 분포를 위로 밀 뿐이다. PR과 최고 F1이 기준보다 낮고, 최적 threshold가 0.73~0.96으로 치우친다.
4. **학습 Window는 최대 64일로 유지한다.** 최대 32일로 학습하면 2.4배 빠르지만, 같은 T=32로 평가해도 PR이 0.055 낮다.
5. **Encoder 깊이를 늘리는 것(3-3-2)은 이득이 없다.** 성능은 비슷하거나 낮고 1.5배 느리다.
6. **Decoder 깊이를 늘려도(2-2-3) 이득이 없다. 2-2-2를 기본 구조로 유지한다.**
   - fold 0(고정 LR)에서는 2-2-3이 PR +0.02 높았다.
   - cosine LR을 쓴 fold 1·2에서는 차이가 없거나 2-2-2가 약간 낫다(PR +0.005 / −0.007, F1 −0.003 / −0.009).
   - fold 0에서 cosine을 쓴 2-2-2가 고정 LR 2-2-3과 같은 수준(PR 0.635)이었다. 따라서 fold 0에서 본 2-2-3의 우위는 고정 LR의 불안정 때문이었을 가능성이 크다.
7. **Cosine LR(+2% Warmup)을 채택한다.** 같은 fold 0, 2-2-2에서 고정 LR과 비교했다.
   - 마지막 epoch이 0.884 / 0.600 / 0.619 → 0.893 / 0.630 / 0.640으로 올랐다.
   - Epoch 간 급락이 사라졌다. 고정 LR은 PR이 0.615 → 0.345 → 0.617로 출렁였고, cosine은 ep6~9 동안 0.627~0.635였다.
   - best.pt와 마지막 epoch 성능이 거의 같아져서 checkpoint 선택에 덜 민감하다.
8. **평가 Window는 T=32와 T=64가 비슷하고 T=1은 크게 나쁘다.** 비겹침 Window 추론을 유지한다.

## 6. Cosine LR + best.pt F1 기준 (fold 1)

변경 사항(커밋 a92e117)은 다음과 같다.
- LR: 처음 2% 구간 선형 Warmup 후 0까지 코사인 감소. 진행률은 본 샘플 수로 잰다.
- best.pt 선택 기준: `metric_primary: f1` (T=64, threshold 0.5)

| 구조 | best.pt (F1 기준) | 마지막 epoch | PR 최고 | 최고 F1 (threshold) |
|---|---|---|---|---|
| 2-2-2 | 0.942 / 0.712 / 0.705 (ep9) | 0.942 / 0.712 / 0.705 | 0.712 | 0.707 (0.46) |
| 2-2-3 | 0.945 / 0.717 / 0.702 (ep8) | 0.945 / 0.714 / 0.697 | 0.717 | 0.704 (0.47) |

- 두 구조의 차이는 측정 오차 수준이다.
- 최적 threshold가 0.46~0.47로 0.5에 가깝다. 확률 보정이 잘 되어 있어서 0.5 고정 threshold로 충분하다.
- fold 0(PR ≈ 0.62)보다 전체 수준이 높지만 검증 건물이 달라서 **fold 간 수치는 직접 비교하지 않는다.** 같은 fold 비교는 7절에서 한다.

| fold | ROC | PR | F1 | best.pt epoch | 최고 F1 (threshold) |
|---|---|---|---|---|---|

- 마지막 epoch, T=64 평가 기준이다. T=32로 평가해도 0.918 / 0.662 / 0.664로 같은 수준이다.

## 실험 외 수정 사항

- `best.pt` / `last.pt`를 모두 저장한다.
- 자동 종료(`scripts/run_then_stop.sh`)는 `brev stop`만 쓴다. OS shutdown은 Brev 상태와 어긋나 재시작이 안 되는 문제가 있어 제거했다.
- 3개 이상 실험을 이어 붙일 때 중간에 인스턴스가 꺼지던 문제를 고쳤다(`scripts/queue_then_stop.sh`).
- `--fold`로 바꾼 학습 Fold가 Checkpoint에 남지 않던 문제를 고쳤다(커밋 e167223). 그동안 `threshold_curve`가 다른 Fold 건물로 평가할 수 있었다. 이전 Checkpoint는 `--fold`로 지정한다.
